# General Scientific Analysis Skills

The twenty-two general skills below complement FEZA's existing astronomy skill. They
combine a selected, reviewed source collection with science-first workflow guides,
not every project-specific workflow or subject-matter guide. They are Markdown
instructions and recipes, not installed scientific libraries, executables,
credentials or an analysis pipeline.

Start with [thinking-like-a-scientist](../skills/thinking-like-a-scientist/SKILL.md)

## Install independently

Each skill's complete directory is a self-contained installation unit. References
stay inside it; other skills named in prose are optional helpers, not filesystem
dependencies. Use the [existing installation methods](../INSTALLATION.md#general-scientific-skills)
with the chosen identifier. Keep each directory name equal to its frontmatter name.
Installing the astronomy skill alone does not install this collection.

The navigation implementation, index and checks are preserved as Markdown recipes.
Adapt them in an owned user-project location only when needed and authorized; no
Python module or test suite runs when an assistant loads the guide. Its existing
checks are not new behavioral acceptance of this integration.

## Scientific and distribution boundaries

Follow the receiving project's environment, data access, blinding, review and compute
policies. Nothing here authorizes remote jobs, uploads, commits, publication decisions
or extra agents. Do not create report files or metadata ledgers by default.

Simulation is legitimate scientific software, not fabricated observation. Preserve
its identity and assumptions. Signed weights, natural units, low counts and nuisance
dependence need their actual mathematical contracts, not transferred defaults.
These skills do not replace discipline-specific methods or institutional safety rules.

Only the Python navigation recipes need Python 3.12+ when actually adapted/executed;
the tracked-source index also needs Git. The testing guide is Python-specific. Other
reasoning/review guidance can apply to other languages; the AST recipe does not parse C++.

The [development source index](general-scientific-sources.md) locates the retained
primary documents under ignored local literature. They are not bundled as MIT-licensed
skill material or installation dependencies. No complete source-license audit, client
installation, scientific evaluation or general behavioral-performance claim accompanies
this integration. Project data, protected evaluation answers and private agent settings
were not imported.
